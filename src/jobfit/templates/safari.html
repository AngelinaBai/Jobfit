One-time setup

  1. In Safari, create a bookmark in Favorites and name it Save to JobFit.
  2. Open Bookmarks → Edit Bookmarks.
  3. Find Save to JobFit, edit its address, and replace the existing URL with the code below.
  4. Keep jobfit-web running whenever you use the bookmark.

How to use it

Log in to LinkedIn, Handshake, or your school career portal normally. Open one specific job listing, then click Save to JobFit in Safari Favorites. A JobFit review page opens in a new tab. Check the extracted fields and click Save job.

JobFit does not receive your password, MFA code, cookies, or login session. The bookmark only reads visible job-page text and sends the selected fields to your local JobFit server.
